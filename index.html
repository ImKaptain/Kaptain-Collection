    Save your setup

    This turns on autosave for this browser. After you set a save password, your API keys and collection picks are stored here automatically when you change them. Completely optional.

    Your keys stay on your side.

    We scramble them on this device with your save password before anything is stored. The password is never sent to our servers. This is separate from your Nuvio login.

    Autosave is already set up on this browser. Enter your save password once to restore keys and picks, then changes keep saving on their own until you close the browser.

    Enter the tokens you use with Nuvio once. When Save is unlocked, they fill in automatically later.

    Trakt tokens are saved automatically during the wizard, tied to whichever AIO Metadata host you authorize on (for example Midnight). They are not entered here.

    Why this is safe enough to type keys into

    • Your save password never leaves this device. We do not upload it.
    • API keys and optional Nuvio login details are scrambled on your device before they are stored in this browser.
    • Anyone who opens this site without your save password cannot read that data.
    • Autosave is optional. Skip it and the site works the same as before.
    • This is not the same thing as logging into a Kaptain cloud account. Use “Lock on this computer” if someone else might use this browser.
